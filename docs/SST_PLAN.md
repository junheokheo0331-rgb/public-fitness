# 모두의 창업 제출안 — GymLink SST 계획서

## 한 문장

**내가 선택한 헬스장에 맞는 운동 루틴을 만들고, 회원·트레이너·관장을 예약·관리·비교 데이터로 연결하는 지역 피트니스 운영 플랫폼.**

## P — Problem

### 회원

- 운동 앱이 초보자의 수준을 고려하지 않고, 추천 종목이 실제 헬스장 기구와 맞지 않는다.
- 헬스장을 선택할 때 가격·기구·트레이너 전문분야를 한 화면에서 비교하기 어렵다.
- PT 예약을 개인 메신저로 조율해 시간이 오래 걸리고 변경 기록도 남지 않는다.
- 트레이너의 자격·경력·사례가 흩어져 있어 재활·시니어·입문 등 목적에 맞는 사람을 찾기 어렵다.
- 결제 가격과 중도 해지 기준이 불투명하다.
- 개인 연락처 교환 뒤 회원이나 트레이너가 불쾌한 사적 연락에 노출될 수 있다.

### 트레이너

- 회원별 루틴, 점진적 과부하, 체성분, 숙제, 예약을 여러 앱과 메신저에 나누어 기록한다.
- 이직 시 누적 경력과 포트폴리오를 다시 만들어야 한다.
- 회원이 혼자 운동한 기록을 제때 확인하기 어렵다.

### 관장

- 가격·보유 기구·트레이너 강점을 검색 고객에게 구조화해 보여줄 방법이 부족하다.
- 새로운 플랫폼이 기존 회원관리·출입 시스템을 대체하라고 요구하면 도입 비용과 현장 저항이 커진다.
- 트레이너의 실제 고객 관리 품질을 객관적으로 파악하기 어렵다.

## S — Solution

### 1. 실제 기구 기반 루틴

관장이 머신과 운동 환경을 등록하면 각 기구가 제공하는 운동 역량을 계산한다. 회원 수준·목표·통증 부위를 함께 반영해 **내 헬스장 환경에 자연스럽게 맞는 종목**을 추천한다. 이것이 GymLink의 핵심 차별점이다.

### 2. 지역 비교와 목적 기반 매칭

지도에서 거리순·가격순·별점순으로 헬스장을 비교하고, 원하는 기구와 트레이너 전문분야로 필터링한다. 원하는 트레이너가 없으면 회원이 PT 요청을 올리고 근처 트레이너가 이력과 제안가로 지원한다.

### 3. 예약·숙제·기록의 한 흐름

트레이너가 가능 시간을 열어 두면 회원이 미용실 예약처럼 시간대를 고른다. PT 직후 루틴 사본과 메모를 숙제로 보내고, 회원의 혼자 운동한 기록은 다음 수업의 점진적 과부하 목표에 반영된다.

### 4. 검증 가능한 트레이너 포트폴리오

자격증·경력·대회·회원 사례를 트레이너가 직접 등록한다. 본사가 원본을 확인한 항목만 검증 배지를 붙인다. 이직해도 앱 안의 이력은 유지된다.

### 5. 안전한 앱 내 대화

회원과 트레이너는 개인 연락처 없이 앱에서 운동·식단·예약을 이야기한다. 전화번호·개인 메신저 ID 유도 문구는 서버에서 마스킹하고, 신고가 접수된 대화만 운영팀이 제한적으로 확인한다.

### 6. 투명한 결제 원장과 기존 출입 시스템 공존

가격표·정가·계약금액을 공개하고 주문 상태와 중도 해지 예상액을 동일한 규칙으로 보여준다. 심사 환경에서는 모의 결제로 회원권 반영까지 검증하고, 운영 결제는 PG 승인 결과만 서버에서 기록해 카드번호를 보관하지 않는다. 관장은 회원 명단을 Excel 호환 CSV로 내려받아 기존 CRM·출입 시스템에 올릴 수 있다.

## T — Traction / Target

### 초기 목표 고객

- 헬스장을 처음 등록하거나 루틴을 어려워하는 20–39세 모바일 회원
- 회원 20–80명을 관리하며 이직 가능한 포트폴리오가 필요한 트레이너
- 회원 100–800명 규모의 단일 지점 또는 소규모 체인 관장

### 검증 지표

1. 입점 헬스장의 보유 기구 등록 완료율 80% 이상
2. 기구 맞춤 루틴 생성 후 첫 운동 시작률 40% 이상
3. PT 요청당 유효 제안 3건 이상
4. 예약 조율 메시지 수 50% 감소
5. 트레이너가 보낸 숙제의 주간 완료율 60% 이상
6. 4주차 회원 재방문율과 입점 헬스장 유지율

## 경쟁과 포지셔닝

| 구분 | 강점 | GymLink의 차이 |
|---|---|---|
| 다짐형 서비스 | 헬스장 이용권 탐색·가격 비교 | 가격뿐 아니라 실제 기구 → 가능한 운동까지 연결 |
| 짐워크형 서비스 | 운동 루틴·기록 | 특정 헬스장 보유 기구와 관장·트레이너 운영 흐름 연결 |
| 헬스장 CRM | 회원·결제·출입 운영 | 소비자 탐색·트레이너 포트폴리오·루틴 경험까지 연결 |
| 개인 메신저 | 빠른 대화 | 업무 기록 보존, 개인 연락 우회, 신고·마스킹 |

## Scale-up

1. 관장이 보유 기구로 “오늘의 운동 오마카세”를 공개한다.
2. 식사 사진은 서버 함수에서 AI로 요약하고 영양 참고 정보를 트레이너와 회원에게 함께 보여준다. 의료 진단·처방 표현은 쓰지 않는다.
3. LookinBody Web API 제휴가 가능한 지점은 OAuth/API로 체성분 숫자를 연동하고, 그렇지 않은 지점은 기기 내 OCR 또는 CSV 가져오기를 사용한다.
4. PG·정산·환불·전자금융 규제 검토가 끝난 뒤 앱 결제와 플랫폼 커미션을 단계적으로 연다.
5. 운동식품·의류는 직접 재고를 보유하기보다 제휴 링크·선별 스토어부터 검증한다.

## 수익 모델

- 1단계: 헬스장 월 구독(기구 노출, 예약, 회원 CSV, 추천 루틴)
- 2단계: 트레이너 검증 포트폴리오와 고급 회원관리 요금제
- 3단계: 법률·PG 구조 확정 후 거래 수수료
- 4단계: 식품·용품 제휴 매출과 체인용 운영 분석

## MVP 범위

현재 데모는 회원·트레이너·관장·본사 네 화면, 기구 기반 루틴, PT 요청·지원, 예약, 운동 기록, 체성분 OCR, 숙제, 사진 대화, 신고, 공개 가격표, 주문·모의 결제, 회원 CSV를 포함한다. 실거래 PG 승인·정산, AI 식단 분석, 외부 출입기 직접 제어는 제휴와 규제 검토 뒤 활성화한다.

## 8주 실행안

- 1–2주: 부산진구 헬스장 3곳 인터뷰, 기구 등록 시간과 가격표 입력 검증
- 3–4주: 회원 30명 비공개 테스트, 루틴 생성→첫 운동 퍼널 측정
- 5–6주: 트레이너 10명 예약·숙제·점진적 과부하 테스트
- 7주: 신고 대응·권한정책·개인정보 동의 점검
- 8주: 핵심 지표와 인터뷰 결과로 유료 전환 및 결제 2단계 판단
